# Movie Explorer

## Summary

Movie Explorer is a premium movie discovery web application. Users browse trending and genre rows, search titles, open rich movie details, and keep a personal watchlist.

## Users

Cinema enthusiasts and casual viewers who want to find something to watch without opening a full streaming app. Primary context: evening browsing on desktop or phone.

## Jobs

- Discover movies by genre and trending lists.
- Search by title and open full details (cast, trailer, ratings).
- Save titles to a persistent watchlist for later.

## Positioning

A polished movie finder with Netflix-style browse rows — not affiliated with TMDB or any streaming service.

## Platform

web

## Stack

Plain static HTML5, CSS3, and vanilla JavaScript (ES modules). Deployable to GitHub Pages. Movie data from The Movie Database (TMDB) API.
